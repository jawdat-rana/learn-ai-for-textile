# Prompt kits: reusable tools for everyday textile work

Each kit is a ready-made prompt you can reuse every week. Each one comes with
a made-up sample so you can try it safely, a description of what a good
answer looks like, and a **"where AI is wrong"** section.

| Kit | Use it when | Time saved (typical) | Code? |
|---|---|---|---|
| [Supplier sustainability data check](supplier-sustainability-data-check.md) | Supplier questionnaires come back and you need to know what's usable for your LCA | 1-2 hours per batch | No |
| [Green claims check](green-claims-check.md) | Before marketing copy, hangtags or a sales deck go out | First pass in minutes | No |
| [LCA scope and consultant brief](lca-scope-and-consultant-brief.md) | Before asking consultants for an LCA quote | Half a day | No |
| [Lab test report to plain English](lab-report-to-plain-english.md) | A biodegradation, shedding or chemical test report needs explaining to non-specialists | 30-60 min per report | No |

**How to save a kit so you reuse it:** keep the prompt in your
[journal](../my-ai-journal.md), or turn it into a reusable skill or custom
assistant in [Part 2](../part-2-advanced/README.md).
